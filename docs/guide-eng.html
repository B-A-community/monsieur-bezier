Monsieur Bézier 1.0 — quick guide

SketchUp 2024 / 2025 / 2026 extension: a Bézier pen — smooth and corner nodes, just like in vector editors

1Installation

SketchUp → Window → Extension Manager → Install Extension → pick monsieur_bezier-1.0-eng.rbz → restart SketchUp. You get the “Monsieur Bézier” toolbar (one button) and the Extensions → Monsieur Bézier menu. If the toolbar is gone — View → Toolbars → Monsieur Bézier.

2Drawing a curve

The toolbar button or Extensions → Monsieur Bézier → Bézier curve.

clickcorner node — the span into it is straight
click and dragsmooth node — you pull a handle, the other one mirrors it
click the first nodeclose the curve
Enter or double-clickfinish
Escstep back — remove the last node
number + Entersegments per span (1 to 200, default 12) — in the “Segments” box, bottom right

Step back is Esc, not Backspace. Backspace and Enter belong to the input box: while a number is typed there, Enter applies the number instead of finishing the curve.

3What you get

  • Every span between two nodes is a separate curve: a single click selects one span, so you can edit or delete it on its own.
  • A triple click selects the whole chain — like any connected edges in SketchUp.
  • A span between two corner nodes is a single straight edge, with no extra points.
  • Spans share their end vertices, so for Follow Me the chain is one continuous path.
  • The whole curve is one operation: Ctrl+Z undoes it at once.
