Monsieur Bézier 1.0 — краткая инструкция

Плагин SketchUp 2024 / 2025 / 2026: перо для кривых Безье — гладкие и угловые узлы, как в векторных редакторах

1Установка

SketchUp → Window → Extension Manager → Install Extension → выбрать monsieur_bezier-1.0-rus.rbz → перезапустить SketchUp. Появится панель инструментов «Monsieur Bézier» (одна кнопка) и меню Extensions → Monsieur Bézier. Если панель пропала — View → Toolbars → Monsieur Bézier.

2Рисование кривой

Кнопка на панели или Extensions → Monsieur Bézier → Кривая Безье.

кликугловой узел без ручек
клик с протяжкойгладкий узел — тянете ручку, вторая зеркалится сама
клик по первому узлузамкнуть кривую (от трёх узлов)
Enter или двойной кликзакончить
Escшаг назад — убрать последний узел
число + Enterсегментов на пролёт (от 1 до 200, по умолчанию 12) — в поле «Сегментов» в правом нижнем углу

Шаг назад — Esc, а не Backspace. Backspace и Enter нужны полю ввода: пока там набрано число, Enter применяет число, а не заканчивает кривую.

3Что получается

  • Каждый пролёт между двумя узлами — отдельная кривая: один клик выделяет один пролёт, его можно править или удалить отдельно.
  • Тройной клик выделяет всю цепочку — как любые связанные рёбра SketchUp.
  • Пролёт между двумя угловыми узлами — одно прямое ребро, без лишних точек.
  • Стыки пролётов — общие вершины, поэтому для Follow Me цепочка — один непрерывный путь.
  • Вся кривая создаётся одной операцией: Ctrl+Z отменяет её целиком.
Узел 2 — гладкий (ручки зеркальны), узлы 3 и 4 — угловые: пролёт 3 прямой. Каждый цвет — отдельная кривая.
