# Monsieur Bézier

Плагин SketchUp для гладкой геометрии: фаска и скругление рёбер с честной
сшивкой углов, плюс перо для кривых Безье.

Версия 0.3 · SketchUp 2024 и 2025 · лицензия [Apache 2.0](LICENSE) · © 2026 B&A community

Создатели: [maksarsanjeev](https://github.com/maksarsanjeev),
[Royalb21](https://github.com/Royalb21) — см. [AUTHORS](AUTHORS).

Сделано по заявке из чата архитекторов: «нормальный Chamfer — выбираешь грани,
задаёшь размер фаски, количество сегментов; 1 сегмент — прямая фаска, больше —
скругление» и «сплайнов Безье тоже не хватает».

## Фаска и скругление

Выделите рёбра — или сразу группу целиком, тогда возьмутся все её рёбра, — и
нажмите кнопку. В окне два слайдера — **размер** и **сегментов** — и
переключатель, **как считать размер**. Пределы слайдеров настраиваются и
запоминаются; число можно вбить и руками, за пределом слайдера тоже.

- **Сегментов = 1** — прямая фаска.
- **Сегментов > 1** — скругление; чем больше, тем глаже и тем тяжелее модель.
- **Катет** — отступ от ребра по каждой грани («фаска 20 мм» на чертеже).
  **Радиус** — радиус скругления. Одно пересчитывается в другое через угол
  между гранями, внутри плагин всегда живёт радиусом.

Пока крутишь слайдеры, во вьюпорте перерисовывается зелёный каркас будущего
результата — модель при этом не меняется, считается только план. Подобрал на
глаз — **Enter** применяет; Esc в окне убирает превью. Флажок «показывать,
пока кручу» можно снять на тяжёлых выделениях, тогда превью — по кнопке
«Показать». «Применить» делает всё одной операцией — отменяется одним Ctrl+Z.

Слишком большой размер — отступ съедает грань или полоса длиннее своего ребра —
отклоняется с объяснением ещё до превью, а не строится кашей.

### Почему не «вырезать цилиндром»

Обычный способ сделать фаску в SketchUp — протянуть профиль вдоль ребра и
вычесть булевой операцией. Так работает большинство самоделок, и у этого три
беды: нужен SketchUp Pro и замкнутый солид, теряются материалы, а на стыке трёх
рёбер вместо угла получается «клюв» — три цилиндра пересекаются, но угол между
ними ничем не закрыт.

Здесь сделано топологически: смежные грани подрезаются на величину отступа,
вдоль ребра встаёт полоса из сегментов, а в вершинах полосы сшиваются между
собой. Pro не нужен, солид не нужен, материалы граней сохраняются.

### Как сшиваются углы

| В вершине сошлось | Что делает плагин |
|---|---|
| одно ребро | полоса режется плоскостью грани, в которую ребро упирается — торец ложится ровно в неё |
| два ребра | ус: обе полосы кончаются одной и той же ломаной, шва не остаётся |
| три ребра | оси дуг сходятся в центре вписанной в угол сферы; полосы режутся через него, дырка закрывается сферическим треугольником |
| четыре и больше | пока не поддержано — такие рёбра пропускаются с объяснением |

### Чем проверено

Не «не падает», а совпадает с аналитикой:

- одно ребро коробки, 6 сегментов — объём совпал с расчётным до 6 знака;
- вогнутое ребро — материал прибавился ровно на расчётные 4023.772;
- прямая фаска по всем 12 рёбрам — 501000 при аналитических 600000 − 99000
  (срезается 5/6·d³ на угол);
- скругление по всем 12 рёбрам — сходится к формуле Штейнера для суммы
  Минковского с шаром: ошибка падает вчетверо при удвоении числа сегментов
  (0.398 % → 0.102 % → 0.026 %), то есть аппроксимация второго порядка;
- на каждом шаге результат остаётся валидным солидом (`manifold?`).

## Кривая Безье

Перо, как в векторных редакторах:

| Действие | Что происходит |
|---|---|
| клик | угловой узел, пролёт до него прямой |
| клик с протяжкой | гладкий узел, тянется ручка (вторая зеркалится сама) |
| клик по первому узлу | замкнуть кривую |
| Enter или двойной клик | закончить |
| Esc | шаг назад: убрать последний узел (как у «Линии») |
| число в поле ввода + Enter | сегментов на пролёт (по умолчанию 12) |

Клавиши намеренно не перехватываются: Enter и Backspace нужны полю ввода.
SketchUp сам разводит их — при пустом поле Enter заканчивает кривую, при
набранном числе применяет число.

Результат — по кривой (`add_curve`) на каждый пролёт между узлами, а не одна
на всю цепочку: пролёт выделяется одним кликом и правится отдельно, вся
цепочка — тройным кликом. Прямой пролёт между двумя угловыми узлами остаётся
одним ребром, лишних вершин на прямой не появляется. Стыки SketchUp склеивает
в общую вершину, так что для Follow Me это по-прежнему один путь.

## Статус

**0.3 — тестовая сборка. Релиза нет, готовый пакет не выкладывается.**

## Установка

Собрать пакет (см. «Сборка») и поставить: SketchUp → **Расширения → Менеджер
расширений → Установить расширение**. Панель появится сама; вернуть её потом
можно через **Вид → Панели инструментов → Monsieur Bézier**. После установки
SketchUp нужно перезапустить — Ruby-файлы кешируются.

## Структура

```
src/
  monsieur_bezier.rb               регистратор расширения
  monsieur_bezier/
    main.rb                        точка сборки
    settings.rb                    предпочтения в реестре SketchUp
    geom_utils.rb                  векторная мелочь: slerp, пересечения, допуски
    chamfer_math.rb                разбор ребра и профиль — чистый счёт
    chamfer.rb                     план узлов и граней, сборка геометрии
    chamfer_panel.rb               окно фаски и превью во вьюпорте
    bezier.rb                      кубическая кривая и цепочка
    bezier_tool.rb                 перо
    toolbar.rb                     панель инструментов и меню
    html/chamfer.html              разметка и оформление окна
    icons/                         *.svg (Windows) + *_24.png / *_16.png (фолбэк)
test/
  sketchup.rb                      заглушка SketchUp API для прогона без SketchUp
  test_bezier.rb                   перо: пролёты, стыки, что кладётся в модель
tools/
  build_rbz.ps1                    собирает src/ в monsieur_bezier<версия><суффикс>.rbz
(пакет собирается локально, в репозиторий не кладётся)
```

Пространство имён — `BACommunity::MonsieurBezier`.

Расчёт и правка модели разведены намеренно: `Chamfer.plan` ничего не меняет,
только считает, поэтому его же результат идёт и в превью, и в сборку. Ошибку
видно до того, как что-то сломалось.

## Тесты

Перо проверяется обычным Ruby 3.2 без SketchUp — на заглушке API:

```bash
ruby test/test_bezier.rb
```

Движок фаски так не проверить: ему нужны настоящие грани и петли. Его
цифры выше получены в живом SketchUp.

## Сборка

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_rbz.ps1"
```

Имя пакета собирается само: версия читается из `src/monsieur_bezier.rb`, а к ней
добавляется суффикс, по умолчанию `_test`. Когда решим катить в прод:

```bash
powershell -ExecutionPolicy Bypass -File "tools\build_rbz.ps1" -Suffix ""
```

## Ещё не решено

- Узлы, где сходятся четыре и больше скругляемых рёбер: сейчас пропускаются.
- Разный радиус на разных рёбрах в одном заходе.
- Пересекающиеся подрезки: если две фаски на одной грани съедают общий кусок,
  плагин честно отказывается вместо того, чтобы выдать кашу.
- Параметрическая фаска «как модификатор в Blender»: сейчас результат
  бетонируется в геометрию. Чтобы изменить — Ctrl+Z и заново.
- Выпуклость ребра определяется по нормалям граней — у группы с вывернутыми
  наизнанку гранями сторона новых полос может оказаться обратной.
- У пера нет перетаскивания уже поставленных узлов и разлома ручек.

## Грабли

- `Point3d#distance`, `Vector3d#length` и вообще всё, что возвращает `Length`,
  сравнивается **с допуском 0.001"**: `0 < 0.001` даёт `false`. Из-за этого
  совпавшие точки не склеивались, а угол не сводился к сфере. Везде, где
  сравниваем длины с малым порогом, обязателен `.to_f`.
- Инструмент, который перехватывает Enter в `onKeyDown` и возвращает `true`,
  ломает поле ввода: SketchUp не успевает применить набранное число. Для
  Enter есть штатный `onReturn`, он вызывается только при пустом поле.
- `UI.messagebox` внутри инструмента — модальное окно: блокирует и SketchUp,
  и мост для тестов. Для мелких ошибок ввода — `UI.beep` и строка состояния.
- `main.rb` подключает файлы через `require`: при разработке повторный
  `load main.rb` старый код не заменит, файлы надо `load`-ить по одному.
- `Entities#add_face` не принимает неплоские четырёхугольники — клетки
  сферического патча лежат на сфере, их приходится резать на треугольники.
- `.rbz` — обычный ZIP, `monsieur_bezier.rb` должен лежать **в корне** архива,
  а пути внутри — через прямой слэш.
- SVG-иконки понимает только Windows-версия SketchUp (2016+); на macOS нужен
  PDF, поэтому там код откатывается на PNG.
- Если папка проекта содержит не-ASCII символы (например, «Bézier»), `ruby`
  из консоли с кодировкой 866 получает путь скрипта уже испорченным, и
  `require` в тестах не находит файлы. Лечится `chcp 65001` перед запуском;
  у клона с GitHub имя папки ASCII, там этого нет.
